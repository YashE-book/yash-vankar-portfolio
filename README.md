# Yash Vankar — Portfolio

A responsive React + Vite portfolio inspired by the dark, minimal, red-accented style in the reference video.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
npm run preview
```

Deploy the generated `dist` folder to Vercel, Netlify, or any static hosting provider.
